# Media

- `banner.png` (2:1, the catalog and README banner), `social-card.png` (16:9) and `features.png` (2:1) are
  generated artwork in the Hermes announcement style.
- `screenshot-*.png` are real captures of Hermes Desktop running this plugin against a remote gateway, at 2x.

Images used by the plugin catalog are pinned to a release commit, so replace a file in a new commit rather than
rewriting history.
